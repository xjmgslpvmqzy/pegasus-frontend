## Overview

Pegasus is a highly customizable retro game launcher frontend for desktop and embedded platforms, using QML-based theme definitions that give complete visual freedom. It integrates with multiple metadata scrapers, supports virtually any emulator, and runs on Windows, Linux, macOS, Raspberry Pi, and Android with a fully themeable game library interface.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Pegasus Frontend** delivers the features you need in a clean, intuitive package.

> Official website: [pegasus-frontend.org](https://pegasus-frontend.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **QML Themes** | Fully themeable interface via QML scripting with community theme library |
| **Metadata Scraping** | Scrape game metadata and artwork from multiple online sources |
| **Multi-Platform** | Runs on desktop, Raspberry Pi, Android, and embedded Linux devices |
| **Universal Emulators** | Launches any emulator via configurable command and argument templates |
